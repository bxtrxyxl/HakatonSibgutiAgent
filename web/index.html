Пересборка полностью обновляет FTS-индекс и эмбеддинги. Папка должна находиться внутри data/.

Каталог направлений 38 профилей с дисциплинами, профессиями и проходными баллами. Используется для подбора по стеку.
—

Каталог обновляется с portal.sibsutis.ru и не меняет основную базу, пока вы не запустите пересборку.

Полная пересборка с сайта Находит страницы СибГУТИ и заново собирает базу знаний. Перед запуском автоматически создаётся резервная копия.
—

Задача идёт в фоне. Если сайт не отдал ни одного документа, база восстановится из копии.

Обновление данных по кнопке Запускается только вручную: обновляет каталог, достижения, минимальные баллы и ссылки парсинга, сохраняя прежние записи при ошибках.
—

Задачи выполняются по одной. При сбое части источников старые данные не теряются.
