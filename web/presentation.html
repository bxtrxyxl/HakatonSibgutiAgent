Зачем это нужно

Информация есть.
Но искать её долго.

проблема 1

Разрозненные источники

Правила приёма, приказы, программы, общежития и стипендии лежат в разных разделах сайта и PDF.

проблема 2

Обычный чат-бот выдумывает

Без базы знаний модель может придумать срок, балл или стоимость. Для вуза это недопустимо.

проблема 3

Нет доверия к ответу

Абитуриенту нужен не просто текст, а ссылка на официальный документ, который можно проверить.

Нужен ответ за минуту, с фактами и источником — а не 20 открытых вкладок.

Зачем три таблицы

Источник, текст и поисковый индекс разделены, чтобы не дублировать логику.

Связь

chunks.id связывает обычную таблицу с FTS. Один чанк — одна строка.

Сейчас

9 документов, 179 чанков. Число чанков должно совпадать с числом векторов.

WAL-режим ускоряет чтение и уменьшает блокировки. Рядом могут появляться -wal и -shm — это нормально.
kb.sqliteТексты, метаданные и поиск в одном файле
Векторы

Как работает embeddings.npy

чанк 1чанк N
1024 числа на строкуfloat32

Что это

Каждая строка — числовой «смысл» одного чанка. Похожие тексты дают близкие векторы.

Связь с базой

Строка i соответствует chunks.id по возрастанию. Число строк должно совпадать.

Если не совпало

Поиск остановится и попросит пересобрать базу. Это защита от «полубазы».

cosine(a, b) = a · b   — векторы уже нормализованы до длины 1
Векторы считаются батчами по 32. Если API отклоняет батч, он дробится, чтобы один плохой текст не ронял весь документ.
embeddings.npyСмысл в виде матрицы, а не магия

Выбор технологий

Почему именно так

данные

SQLite + FTS5

Не нужен Docker и внешний сервер. База — один файл, который легко скопировать и откатить.

поиск

Гибрид, а не только векторы

Коды и даты лучше ищутся словами, общие вопросы — по смыслу. Вместе точнее.

фронтенд

Один HTML

Нет React, npm и сборки. Открыл файл — работает. Легко заменить на другой UI.

секреты

Ключи на сервере

Браузер не видит API-ключи. Ошибки очищаются, логи не содержат токенов.

pip install -r requirements.txt
python -m src.ingest --dir data/docs
uvicorn src.api:app --host 127.0.0.1 --port 8000
