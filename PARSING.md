## 2. Направления и профили

Главный источник — портал абитуриента:

- индекс: `https://portal.sibsutis.ru/abitur/profile/`
- карточка профиля: `https://portal.sibsutis.ru/abitur/profile/detail.php?ID=<ID>`
- пример: `https://portal.sibsutis.ru/abitur/profile/detail.php?ID=6131`

На странице профиля есть всё, что нужно для подбора:

- институт;
- код и название направления;
- название профиля;
- уровень: бакалавриат, специалитет, магистратура;
- форма обучения и срок;
- бюджетные и платные места;
- проходной балл 2026;
- стоимость семестра;
- описание программы;
- профилирующие дисциплины со стеком;
- профессии выпускников;
- средняя зарплата;
- вступительные испытания;
- ссылка на учебный план в PDF.

Сейчас автоматически собирается **38 профилей**. Результат лежит в `data/programs.json`.

## 3. Баллы за индивидуальные достижения

Отдельной HTML-страницы нет. Нужный документ — **Приложение 3** к правилам приёма:

`https://sibsutis.ru/upload/iblock/a08/Приложение 3 Перечень и порядок учета индивидуальных достижений при поступлении в СибГУТИ и филиалы.pdf`

Ссылка находится на странице `https://sibsutis.ru/abitur/bachelor/`.

В PDF: перечень достижений, сколько баллов дают, максимум 10 баллов для бакалавриата/специалитета и 50 для магистратуры, требования к подтверждающим документам.

В базе знаний уже есть нормализованная выжимка: `data/docs/Поступление/vstupitelnye-ispytaniya-2026.md`.

Структурированная версия собирается автоматически:

```bash
python -m src.ingest --achievements
python -m src.ingest --min-scores
```

Результаты:

- `data/achievements.json`: 20 достижений бакалавриата/специалитета, 17 магистратуры и 1 целевое, максимумы 10/50;
- `data/min_scores.json`: 7 предметов СОО, 7 предметов СПО/ВО и порог 35 для магистратуры.

API: `GET/POST /api/achievements`, `GET/POST /api/min-scores`.

## 5. Что уже автоматизировано

### Сбор каталога направлений

```bash
python -m src.ingest --programs
```

Что делает:

1. Открывает индекс профилей.
2. Находит все ссылки `profile/detail.php?ID=...`.
3. Скачивает каждую карточку.
4. Достаёт код, направление, профиль, места, баллы, стоимость, дисциплины, профессии, зарплату, экзамены и учебный план.
5. Пишет `data/programs.json`.

### Сбор ссылок для обновления базы

```bash
python -m src.ingest --site-sources
```

Что делает:

1. Берёт ключевые страницы приёмной кампании, общежитий, стипендий и каталога.
2. Добавляет 38 профилей.
3. Находит PDF-приложения по ключевым словам и добавляет закреплённые PDF: итоги приёма 2026, размеры стипендий 2026/2027, тарифы общежитий.
4. Пишет `data/site_sources.json`.

Сейчас находится **около 77 источников**: число зависит от того, какие PDF найдены на странице приложений. Если портал или страница приложений недоступны, сборщик сохраняет ранее найденные профили и PDF и пишет предупреждение в stderr, а не падает.

### API

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/api/programs` | Отдаёт каталог направлений |
| POST | `/api/programs/refresh` | Обновляет каталог с сайта |
| POST | `/api/recommend` | Подбирает направления по стеку или профессии |
| POST | `/api/site/sources` | Обновляет список ссылок для парсинга |
| POST | `/api/site/refresh` | Собирает ссылки; с `ingest=true` пересобирает базу |

В интерфейсе это кнопки **«Обновить с сайта»** и **«Показать ссылки парсинга»** во вкладке «База данных».

## 6. Как работает подбор направления

Пользователь пишет в чат что-то вроде:

- «Хочу работать с Python и машинным обучением».
- «Подбери направление под backend на Java».
- «Где учат фронтенду и TypeScript?».
- «Какие направления подходят для сетей и телекоммуникаций?».

Агент:

1. Понимает, что это запрос на подбор.
2. Раскладывает запрос на смысловые группы: `python`, `ml`, `backend`, `frontend`, `security`, `network` и т.д.
3. Сравнивает группы с полями профиля:
   - название профиля и направления;
   - профилирующие дисциплины;
   - профессии выпускников;
   - описание.
4. Считает совпадение: чем больше групп совпало и чем глубже они в дисциплинах/профессиях, тем выше процент.
5. Возвращает таблицу top-5 и подробности по top-3: что изучают, кем работают, проходной балл, места.

Процент — ориентир по совпадению стека, а не гарантия поступления.

## 7. Что осталось

1. **Планировщик.** Сейчас обновление ручное. Дальше — cron/фоновый worker, который сам запускает `--programs`, `--achievements`, `--min-scores` и `--site-sources`.
2. **Полная пересборка из сайта.** Эндпоинт `/api/site/refresh` с `ingest=true` уже есть, но операция долгая и синхронная. Нужен прогресс и очередь.
3. **Проверка изменений.** Нужно сравнивать хэши страниц и обновлять только изменившиеся профили.
4. **Глубина обхода.** Сейчас один уровень: индекс → профили и ключевые страницы. Новости и второстепенные разделы не обходятся.

## 8. Ограничения

- Сайт может менять вёрстку — парсер профилей привязан к текущим классам и заголовкам.
- Часть страниц отдаётся только после авторизации, их не трогаем.
- PDF бывают с плохим текстовым слоем; для них нужен ручной контроль.
- Проходные баллы и количество мест — на 2026 год.
- Каталог не заменяет основную базу знаний: он дополняет её для подбора.
