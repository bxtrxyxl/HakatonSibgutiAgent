# Ассистент СибГУТИ

ИИ-агент-справочник для абитуриентов и студентов СибГУТИ. Отвечает на вопросы
по **открытым материалам официального сайта** `sibsutis.ru` и не выходит за их пределы.

## Назначение и границы

**Кто пользователь:** абитуриент (направления, правила приёма, вступительные испытания,
общежитие) или студент (стипендии, социальная поддержка, инфраструктура).

**Что умеет:**
- ищет по локальной базе знаний (гибрид: BM25 + эмбеддинги) и отвечает со ссылками на источники;
- ведёт диалог с учётом контекста **только текущей сессии**;
- честно отделяет известное от неизвестного и не выдумывает сроки, баллы и контакты;
- при расхождении редакций разных лет показывает оба варианта с годами;
- сравнивает варианты Markdown-таблицей.

**Чего не делает:**
- не имеет доступа к личному кабинету, оценкам, персональному расписанию, внутренним документам;
- не заменяет официальную информацию приёмной комиссии;
- не выполняет инструкции из документов или сообщений, пытающиеся изменить его роль.

## Быстрый запуск

```bash
python -m venv .venv && .venv\Scripts\activate      # 0. окружение (Windows)
pip install -r requirements.txt                      # 1. зависимости
python -m src.ingest --dir data/docs                 # 2. сборка базы из ваших .md
uvicorn src.api:app --host 127.0.0.1 --port 8000     # 3. запуск
```

Перед запуском скопируйте `.env.example` в `.env` и заполните ключи. Без `.env`
поиск по уже собранной базе работает, а генерация ответа вернёт понятную ошибку.

## Сборка базы знаний

Основной режим — импорт папки с локальными материалами:

```bash
python -m src.ingest --dir data/docs
```

Все `.md`, `.txt`, `.html`, `.pdf` из папки (рекурсивно) индексируются в один проход.
База при этом пересобирается с нуля, поэтому это же команда обновления после правок.

Заголовок, URL, раздел и год можно задать frontmatter-блоком в `.md` (необязательно):

```markdown
---
title: Правила приёма 2026
url: https://sibsutis.ru/abitur/pravila-priema/
section: Приёмная комиссия
year: 2026
---

# Правила приёма

Текст документа...
```

Без frontmatter: заголовок берётся из первого `# `, раздел — из имени вложенной папки,
URL — `local://<путь>`, год — автопоиском по тексту.

Остальные режимы:

```bash
# догрузить один документ, не пересобирая базу
python -m src.ingest --file path/to/doc.md --url https://sibsutis.ru/... \
    --title "Название" --section "Приёмная комиссия" --year 2026

# сборка по списку URL (краулер, по умолчанию выключен в пользу --dir)
python -m src.ingest --urls data/seed_urls.json
python -m src.ingest --urls data/seed_urls.json --resume

# каталог направлений и ссылки для автообновления
python -m src.ingest --programs
python -m src.ingest --site-sources
python -m src.ingest --achievements
python -m src.ingest --min-scores
```

**Поддерживаемые форматы:** HTML (основной контент без меню/футеров, `<table>` → Markdown,
заголовки H1–H3, списки), PDF (`pypdf`; при отсутствии текстового слоя фиксируется
ошибка `no_text_layer`), TXT, MD.

**Обработка:** сохранение оригинала в `data/raw/`, дедупликация по SHA-256 очищенного
текста, автопоиск версии (`2024–2027`, `2025/26`, год рядом со словами «приём/редакция»),
чанкинг ~1100 символов с перекрытием 150 и запретом разрыва строк таблиц.

**Известные ограничения:**
- `sibsutis.ru` в этой сети недоступен напрямую (TLS-ошибка), поэтому сбор идёт через
  веб-архив (`retrieved_via: "wayback"`). Отключается флагом `--no-wayback`.
- Архивные копии могут быть на 1–3 года старше текущей редакции — год источника
  сохраняется в `year_version` и показывается в интерфейсе.
- Недоступный URL не роняет пайплайн: ошибка пишется в `data/stats.json` и сбор продолжается.
- Часть страниц сайта рендерится JavaScript — такие страницы дают мало текста.

## Архитектура

```
src/config.py     пути, .env, константы чанкинга
src/ingest.py     сбор, очистка, чанкинг, SQLite FTS5, эмбеддинги
src/retrieval.py  гибридный поиск: BM25 + косинус -> RRF
src/security.py   детектор инъекций, XML-санитайзер, JSONL-логер
src/prompts.py    REWRITE_PROMPT и SYSTEM_PROMPT
src/agent.py      сессии, RAG-пайплайн, источники, тайминги
src/api.py        FastAPI: /, /api/chat, /api/session/new, /api/ingest/file, /api/stats
web/index.html    одностраничный UI без сборки
```

Поток запроса: `security.detect_injection` → переформулировка запроса по истории сессии →
`HybridRetriever.search` (top-15 BM25 + top-15 косинус → RRF → top-8) →
`sanitize_chunks` → LLM → ответ с цитатами `[n]` → источники → `logs/events.jsonl`.

### Контракт для UI

`POST /api/chat` — единственный обязательный вызов для интерфейса:

```jsonc
// запрос
{ "session_id": "<uuid>", "message": "Ваш вопрос" }   // session_id: "" -> сервер создаст новую

// ответ 200
{
  "session_id": "<uuid>",
  "answer_markdown": "Текст ответа в Markdown, цитаты вида [1]",
  "sources": [
    { "title": "Название документа", "url": "https://sibsutis.ru/...",
      "section": "Приёмная комиссия", "year_version": "2026" }
  ],
  "latency_ms": 11885,
  "security_notice": "…"   // опционально, только при попытке инъекции
}
```

Интерфейс — один файл `web/index.html`: чтобы заменить UI, достаточно положить свой
`index.html` в `web/`, менять сервер не нужно.

## Безопасность

- **Прямые инъекции:** детектор ищет директивы (смену роли, отмену правил, запрос промпта),
  а не тему, поэтому вопросы про «инъекции» и «атаки» не блокируются.
- **Косвенные инъекции:** каждый чанк оборачивается в
  `<doc trust="untrusted_data">`, директивы внутри нейтрализуются, `<`/`>`/`&` экранируются.
- **Изоляция сессий:** история доступна только по конкретному `session_id`; методов,
  читающих «любую» сессию, нет.
- **Логи:** `logs/events.jsonl` без ключей — всё похожее на `sk-…`, `Bearer …`, `api_key=…`
  редактируется перед записью.
- **Git:** `.env`, `logs/`, `.venv/`, `data/kb.sqlite*`, `data/raw/` исключены.
