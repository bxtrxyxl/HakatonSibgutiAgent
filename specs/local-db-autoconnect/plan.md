# План: локальная база из папки проекта и доступ по Wi-Fi

## Архитектура и поток данных
1. Браузер загружает `web/index.html` с сервера (`http://<host>:8000/`).
2. `resolveApiBase(configured)`:
   - если страница открыта по `http(s)` и `configured` — локальный адрес по
     умолчанию (`127.0.0.1` / `localhost`), возвращает `window.location.origin`;
   - если `configured` пуст — origin страницы (или `127.0.0.1:8000` для `file://`);
   - иначе возвращает `configured` без изменений.
3. Все запросы к FastAPI (`/api/chat`, `/api/overview`, `/api/databases`,
   `/api/stats`, `/api/ingest/file`) идут через `resolveApiBase`.
4. `src/api.py::_lifespan` вызывает `ingest.ensure_knowledge_base()`:
   - `check_kb()` → база в порядке, выходим;
   - нет `data/docs` или файлов → пропускаем с сообщением;
   - пробуем embedding API (6 с); при успехе `run_directory(..., with_embeddings=True)`,
     при ошибке — `run_directory(..., with_embeddings=False)`;
   - повторно `check_kb()` для проверки результата.
5. Поиск всегда читает `config.KB_PATH` = `<проект>/data/kb.sqlite`, поэтому
   база локальна для машины-сервера.

## Изменения API
Контракты не меняются. Добавляется внутренняя функция `ensure_knowledge_base()`
и её вызов на старте; ошибки сборки логируются, но не роняют сервер.

## Изменения UI
- Новый helper `resolveApiBase` и его использование в существующих fetch-вызовах.
- При `file://` вкладка «База данных» показывает подсказку запускать `start.bat`
  и открывать `http://127.0.0.1:8000/`.
- Остальные панели, темы, i18n и порядок блоков не меняются.

## Риски и допущения
- Автосборка на старте может занять 15–20 с; `start.bat` собирает базу до
  `uvicorn`, поэтому обычно проверка мгновенная. Ожидание health в лаунчере
  увеличено до 60 с.
- Если embedding API недоступен, база собирается в FTS5-режиме (поиск работает,
  векторный канал отключается).
- Пользователь может явно указать внешний endpoint — он не перезаписывается.
- Тесты `TestClient(app)` без контекстного менеджера не запускают `lifespan`,
  поэтому автосборка не влияет на тестовую базу.
