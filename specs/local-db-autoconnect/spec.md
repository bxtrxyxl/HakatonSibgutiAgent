# Спецификация: локальная база из папки проекта и доступ по Wi-Fi

## Проблема
При открытии страницы агента не с того адреса, на котором запущен сервер
(например, `http://10.242.154.63:8000/` с другого ноутбука, или `web/index.html`
как локальный файл), интерфейс обращается к `http://127.0.0.1:8000` из настроек
по умолчанию. На клиентской машине это её собственный localhost, поэтому:

- правая панель «Актуальное о СибГУТИ» остаётся пустой;
- в «Настройки → База данных» появляется «Сервер базы недоступен: Failed to fetch»;
- чат не получает ответ.

Выглядит это как «бот не может найти базу», хотя база лежит в `data/kb.sqlite`
на машине-сервере. Кроме того, при прямом запуске `uvicorn` на чистом клоне база
не собирается, и поиск падает с «база знаний не найдена».

## Предлагаемое решение
1. **Frontend:** для режима FastAPI по умолчанию использовать origin страницы
   (`window.location.origin`), а не жёсткий `http://127.0.0.1:8000`. Явно заданный
   нелокальный адрес сервера сохраняется как есть. Это чинит LAN-доступ и показ
   с любого хоста.
2. **Backend:** при старте приложения проверять локальную базу в папке проекта
   (`data/kb.sqlite`, источник — `data/docs`). Если база отсутствует, повреждена,
   устарела или не совпадает с векторами — собрать её автоматически; при
   недоступном embedding API перейти на локальный FTS5.
3. Показывать в интерфейсе понятную подсказку, если страница открыта как файл
   (`file://`), а не через запущенный сервер.

## Границы
### Входит
- `web/index.html`: единая функция вычисления API-origin, использование её в
  чате, правой панели, вкладке «База данных», проверке подключения и загрузке файлов.
- `src/ingest.py`: `ensure_knowledge_base()` — локальная сборка из `data/docs`.
- `src/api.py`: вызов автосборки в `lifespan`.
- Тесты на автосборку, обновление `README.md` / `STATE.md`.

### Не входит
- Изменение схемы БД, API-контрактов и логики поиска.
- Загрузка базы в браузер (IndexedDB / File System Access API).
- Настройка брандмауэра и сети (это делает `start-lan.bat` / пользователь).
- Новые зависимости.

## Критерии успеха
- Страница, открытая по LAN-IP, грузит `/api/overview` и `/api/databases` с
  сервера-хоста; правая панель заполнена, вкладка «База данных» показывает
  активную базу, а не «офлайн».
- После удаления `data/kb.sqlite` и запуска `uvicorn` база автоматически
  собирается из `data/docs` (9 документов / 183 чанка), `/api/chat` отвечает.
- При явно заданном внешнем endpoint (не localhost) запросы идут на него.
- `ruff`, `compileall`, `pytest` зелёные.
