# Спецификация: публичная ссылка на приложение через ngrok

## Проблема
Приложение запускается локально на `http://127.0.0.1:8000` (или по LAN-IP внутри
одной Wi-Fi-сети). Для показа жюри или удалённому человеку нужен адрес в интернете.
Открывать порт наружу через брандмауэр и белый IP долго и небезопасно, а на
учебной/гостевой сети входящие соединения часто заблокированы.

`ngrok.exe` уже лежит в корне проекта, но запускать его вручную неудобно: нужно
следить за тем, чтобы сервер был поднят, authtoken был настроен, а ссылка не
потерялась в логе.

## Предлагаемое решение
Добавить `start-public.bat` — один клик, который:
1. проверяет наличие `ngrok.exe` рядом со скриптом;
2. проверяет authtoken ngrok: берёт `NGROK_AUTHTOKEN` из `.env`, иначе один раз
   просит вставить токен и сохраняет его в конфиг ngrok в профиле пользователя
   (не в репозиторий);
3. поднимает приложение через `start.bat` в отдельном окне, если порт 8000 ещё
   не слушается, и ждёт `/api/health`;
4. запускает `ngrok http 8000`, получает публичный URL через локальный API
   `http://127.0.0.1:4040/api/tunnels`, печатает его и открывает в браузере;
5. предупреждает, что ссылка публичная: без `ADMIN_TOKEN` админ-операции открыты,
   а чат расходует кредиты LLM-провайдера.

`ngrok.exe` (33 МБ) и логи туннеля не коммитятся.

## Границы
### Входит
- `start-public.bat`, строка `NGROK_AUTHTOKEN` в `.env.example`, правила в
  `.gitignore`, раздел в `README.md`, обновление `STATE.md` / журнала `HANDOFF.md`.
- Проверка уже запущенного сервера и уже открытого туннеля (повторный запуск не
  плодит процессы).

### Не входит
- Покупка платного домена ngrok, статический URL, OAuth на входе.
- Изменение API, схемы БД, логики поиска и UI-панелей.
- Проброс других портов и настройка брандмауэра (ngrok работает исходящими
  соединениями, входящие правила не нужны).

## Критерии успеха
- `start-public.bat` на машине с настроенным authtoken печатает ссылку
  `https://<random>.ngrok-free.app/` и открывает её.
- По этой ссылке страница загружается, правая панель заполнена, вкладка «База
  данных» показывает активную базу (9 документов / 183 чанка), чат отвечает.
- Без authtoken скрипт объясняет, где его взять, и не оставляет висящих процессов.
- Если сервер уже запущен, второй экземпляр uvicorn не стартует.
- `ruff`, `compileall`, `pytest` остаются зелёными (Python-код не меняется).
