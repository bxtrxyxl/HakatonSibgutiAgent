# План: запуск агента по локальной сети

## Архитектура и поток данных
1. `start-lan.bat` выставляет `HOST=0.0.0.0` и вызывает `start.bat`.
2. `start.bat` использует переопределённый `HOST`, выполняет прежние шаги
   (`.venv` → зависимости → `.env` → база знаний).
3. При `HOST=0.0.0.0` `start.bat` определяет IPv4 интерфейса с шлюзом по умолчанию
   через PowerShell, формирует `URL=http://<LAN-IP>:<PORT>/` и печатает его.
4. `uvicorn` запускается с `--host 0.0.0.0`; проверка готовности идёт по
   `127.0.0.1`, браузер открывается по LAN-ссылке.

## Изменения API
Нет. Все запросы UI идут на тот же origin, CORS не требуется.

## Изменения UI
Нет.

## Риски и допущения
- Брандмауэр Windows может блокировать входящие: скрипт печатает команду для правила,
  но не повышает права автоматически.
- В гостевых Wi-Fi (например, `nstu-free`) может быть изоляция клиентов — это вне
  контроля приложения; для демо рекомендуется хот-спот.
- При пустом `ADMIN_TOKEN` любой в сети получает админ-доступ — скрипт предупреждает.
- Если IP определить не удалось, используется `127.0.0.1` и выводится предупреждение.
